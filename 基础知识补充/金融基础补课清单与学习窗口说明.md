# 衡智金融基础补课清单与学习窗口说明

2026-09-29。状态：课程建议，尚未开始或通过学习验收。用户将在另一个窗口学习；本轮未创建新窗口。目标是理解、设计并检查衡智的账单分析和基金比较，不是短期预测市场或直接形成购买建议。

## 学习方式

按下列顺序学习，先完成1—6，再学7—10。每单元可分多次，每次建议30—45分钟，按实际时间调整，不承诺固定天数学完。每次采用生活例子→概念→小额算例→一道独立练习→纠错→对应衡智字段或规则。公式先说明含义、单位和条件，不要求一开始推导。先做诊断题，已经掌握的内容可跳过。

## 优先掌握：个人财务、账单与基金

### 1. 个人财务与财富的基本结构
- [ ] 收入/支出是期间流量；资产/负债/净资产是时点存量；现金流、利润与财富不是同一概念。
- [ ] 工资、消费、退款、报销、借款、还款、本人账户间转账的区别；借款到账不能当工资收入，自有转账不能重复算收支，偿还本金与利息分开理解。
- [ ] 必要支出、可调整支出、固定支出、一次性支出；应急资金、近期目标与长期资金；保险保障与投资的区别（先认识用途，不开展选品）。
- 练习：为一位虚构上班族做一个月现金流水与月末资产负债表；解释“本月结余3000”为什么不等于“可投资3000”。
- 衡智产出：账单数据字典、不能从账本推断的信息清单。

### 2. 利息、复利与收益口径
- [ ] 本金、利息、单利、复利、机会成本、货币时间价值；名义收益与实际购买力。
- [ ] 区间收益率、年化收益率、累计收益率、算术平均与几何平均；已实现/未实现收益；收益金额与收益率。
- [ ] 七日年化、近一年收益、成立以来年化、业绩比较基准的区别；历史数字不等于未来承诺。
- 练习：100元先涨20%再跌20%，期末96元；解释为什么平均涨跌幅为0但总收益为-4%。解释半年收益不能直接当全年保证。
- 衡智产出：每个收益字段必须附统计期间、计算方式与来源。

### 3. 账单分析与基础统计
- [ ] 总额、笔数、笔均、均值、中位数、分位数；占比、百分点、增长率、金额贡献；环比与同比。
- [ ] 本月至今和上月整月比较的时长差异；零基数、缺记录与真实零消费；节假日及一次性大额影响。
- [ ] 相关性与因果，统计异常与错误/欺诈，误报与漏报，样本不足与个人历史基线。
- 练习：手算一份小账本的分类变化贡献；设计“大额但正常”和“同额但非重复”的反例。
- 衡智产出：报告的事实/推测/待核实问题三栏；保留用户指定本月至今对上月整月口径，不自动改成同期。

### 4. 金融产品与参与机构
- [ ] 存款、银行理财、公募基金、股票、债券各自的基本性质；基金不是存款，平台名称不是产品类型。
- [ ] 销售平台、基金管理人、托管人分别做什么；公募与私募先理解区别，不扩展项目范围。
- [ ] 货币/债券/混合/股票基金，主动/被动、指数基金、ETF与ETF联接、场内/场外。
- 练习：从一份产品资料概要找出产品类型、管理人、托管人、风险和资金投向，不靠平台宣传标签判断。
- 衡智产出：研究产品身份表；不能把理财通视为所有产品的发行或管理机构。

### 5. 基金如何运作、交易与计费
- [ ] 份额、单位净值、累计净值、分红、复权/总回报口径；净值高低不直接代表贵便宜。
- [ ] 认购、申购、赎回、交易申请/确认/到账、交易日与自然日、截止时间、持有期和封闭期；以具体产品文件为准，不背统一到账天数。
- [ ] A/C份额、申购费、赎回费、管理费、托管费、销售服务费；净值已反映的费用避免重复扣除。
- [ ] 正式净值、盘中估值、交易价格及各自时间；不能假定普通场外基金具有实时成交价。
- 练习：用明确的虚构费率计算买入份额和赎回金额；比较不同持有期下两种份额费用。
- 衡智产出：份额代码、费率、流动性、数据时间字段，避免A/C重复充当两种投资策略。

### 6. 风险与适合程度
- [ ] 本金损失、波动、最大回撤、恢复时间；历史回撤不是未来最大可能损失。
- [ ] 市场、信用、利率、流动性、集中度风险；股票与债券收益来源；债券价格与市场利率的基本关系及其条件。
- [ ] 风险偏好、实际承受能力、用款期限；产品风险与是否适合某人分开判断，产品风险标签须注明评定机构。
- 练习：100跌到80损失20%，回到100需上涨25%；比较收益相近、回撤不同的两条净值路径，并说明缺少什么用户信息。
- 衡智产出：不符合条件时排除/资料不足时不判断的规则；不拍脑袋编综合分。

## 随后学习：研究方法、经济背景与应用边界

### 7. 读懂基金文件和比较指标
- [ ] 产品资料概要、招募说明书、基金合同、季报/中报/年报、临时公告各回答什么问题。
- [ ] 投资范围、基准、经理任期、规模、持仓集中、行业暴露；债基的信用质量、久期等；持仓披露滞后。
- [ ] 同类同区间比较；复权、分红、成立时间、份额费率的可比性；认识夏普比率的用途与假设，暂不强求推导。
- 练习：给两只同类基金各做一张有来源/日期/缺失值的资料卡；不必实际购买。
- 衡智产出：五只基金研究池的资料模板与来源审计表，未核实前不指定“稳健10%”。

### 8. 经济学最低限度基础
- [ ] 微观：稀缺、机会成本、供需、边际决策、风险溢价、信息不对称。
- [ ] 宏观：通胀/CPI、经济增长/GDP、就业、利率、信用、货币政策与财政政策；汇率先理解概念。
- [ ] 新闻如何经由盈利、利率、估值和预期影响资产；“降息→所有基金上涨”之类单线推断为何不成立。
- 练习：一条利率新闻分别可能如何影响存款、债券与股票？列出传导机制和不确定条件，不预测涨跌。
- 衡智产出：带条件、来源和时效的新闻解释，不输出确定性行情预言。

### 9. 财富规划、组合与行为偏差
- [ ] 目标/期限/流动性分层；资产配置、相关性、分散化、再平衡；买五只相似基金不一定分散风险。
- [ ] 追涨杀跌、损失厌恶、近期偏差、幸存者偏差、回测过拟合与前视偏差；长期持有和定投也不保证盈利。
- 练习：识别五只基金是否高度重叠，说明仅追踪近期赢家会遗漏什么；讨论框架不设置个人实际仓位。
- 衡智产出：防止重复暴露和历史收益外推的比较提示。

### 10. 金融AI的证据、数据和边界
- [ ] 区分知识解释、客观对比、个性化建议和交易执行；资料/新闻中的事实、意见、预测分开。
- [ ] 数据来源、估值日、发布日期、抓取时间、资料版本、数据缺口；不能用已过期数据冒充实时。
- [ ] 基本适当性概念与风险揭示；具体业务规则需查现行官方材料，不以模型回答替代专业审查。
- [ ] 模型解释与程序计算的分工；无法判断时补充信息或说明局限；输入资料里的指令不具有执行授权。
- 练习：给一份AI生成的账单/基金报告挑错，逐条核对数字、引用、日期、推断和越界承诺。
- 衡智产出：一份报告核查表和一组容易误导用户的反例。

## 暂时延后

期权期货定价、杠杆及高频交易、复杂量化择时、完整计量经济学、宏观预测模型、保险/税务深度选品、全套财务报表估值。未来由实际功能需要触发，不作为当前账单月报的前置。

请按本文件的10个单元带我补金融、经济、财富与投资基础。先给5道不计分诊断题，再从个人财务开始，一次只教一个小主题。每次提供生活例子、关键概念、一个可手算的小例子，再给我一道题并等待我回答，纠错后再继续。每课解释它对应衡智的哪个字段、指标、功能或限制；区分通用原理、具体产品条款、现行规则与假设，涉及产品和规则时查官方资料，附来源和日期。不要默认我懂术语，也不要把课程变成荐股荐基或宏观行情预测。学习状态使用未学/学习中/待巩固/已通过练习，不能讲过就标为掌握。先完成1—6，再继续7—10。
